# MacroPilot · 键鼠宏助手

Windows 桌面端的键盘 / 鼠标宏工具：把**点击、移动、滚轮、按键、等待、激活窗口**等动作编排成「方案」，按设定的循环次数与间隔自动执行。

两种输出后端可切换：

| 后端 | 说明 |
| --- | --- |
| **CH9329 硬件** | 经 USB 串口驱动 CH9329 芯片，在系统层面等同**真实 USB 键鼠**，兼容性最好 |
| **本机模拟** | Win32 `SendInput`，无需额外硬件，可选扫描码 / 虚拟键 |

技术栈：.NET 8 WPF + [WPF-UI](https://github.com/lepoco/wpfui)（Fluent / Win11 外观）+ System.IO.Ports；安装器为 Flutter + 7-Zip SFX 单文件。

---

## 下载与安装

到 **[Releases](https://github.com/pcguan/MacroPilot/releases/latest)** 下载：

| 文件 | 用途 |
| --- | --- |
| `MacroPilotInstaller_Flutter.exe` | **安装器**（约 12 MB）。双击即装，per-user 安装、**无需管理员**；会自动检测 .NET 8 运行时并引导安装 |
| `MacroPilot-app.zip` | **本体文件包**。主要供在线更新使用；手动使用需自备 .NET 8 桌面运行时 |
| `version.json` | 版本清单（版本号 + 各文件大小与 SHA-256），供更新器读取 |

- 默认安装目录：`%LocalAppData%\Programs\MacroPilot`
- 用户数据目录：`%AppData%\MacroPilot`（`plans.json` 方案、`settings.json` 设置、`logs\` 运行日志、`images\` 图片条件模板），可在「配置」页更改并迁移
- 卸载：设置→应用，或安装目录下 `unins\`

## 在线更新

本体自带在线更新：「自动更新」开启时，**启动检查发现新版后自动下载安装**；关闭时跳过启动检查。两种模式都会**每 30 秒后台检查**，发现新版在**窗口底部状态栏**提示，可「立即更新」或「关闭提醒」。关闭提醒后，本次启动期间不再提醒同一版本；手动检查或发现更新版本时会重新提示。

更新前会先处理运行中的方案和未保存修改；下载、校验和安装过程都有可见进度窗：

```
下载(优先本体包) → 校验 SHA-256 → 备份旧目录 → 覆盖 → 保留卸载器
                                              ↓ 失败
                                        自动回滚到旧版本
                                              ↓
                                         重启本体
```

本体退出后，更新助手的小窗会继续显示覆盖和重启进度；失败时显示原因并回滚。

更新源为**有序多源回退**，前者不通自动降级，**不是单点**：

1. `https://nas.pcguan.cn/macropilot/` —— 自建源，**国内直连快**（无需代理）
2. `https://github.com/pcguan/MacroPilot/releases/latest/download/` —— 源头 / 海外回退

版本检测读各源同格式的 `version.json`（普通静态文件，不走 GitHub API，因此不受未鉴权限流影响）。下载完成后**强制校验 SHA-256**，不匹配或下载失败会自动换下一个源重下。

## 主要功能

**方案与动作**
- 多方案管理：新建 / **录制**（做一遍操作自动生成动作列表：点击、连击合并、拖动、滚轮、组合键、等待节奏）/ 复制 / 粘贴 / 重命名（**双击方案名即可就地改**）/ 删除；导入导出（单方案 / 批量，导出文件自包含图片）
- 动作类型分层：**输入 → 鼠标**（点击 / 移动 / 拖动 / 滚轮）、**输入 → 键盘**、**运行 → 等待 / 激活窗口 / 跳转**、**组合**；点击与移动的**点击类型 / 移动类型**（仅点击 / 点击坐标 / 点击图片、移动到坐标 / 移动到图片）与键盘的**输入方式**（按键 / 文本，含修饰键组合捕获）是各自面板里的选项，不占类型行
  - 点击的目标：**当前位置**＝原地点；**坐标**＝先移动到该点再点；**图片**＝区域内搜到目标图再点。移动同理（无「当前位置」）。拖动＝起点按下→移到终点→松开（起终点可跨屏）；拖动还有**拖动窗口**模式：选窗口 + 终点坐标，执行时激活该窗口并按住标题栏把它拖过去；终点坐标对应窗口的哪个点可选（左上角 / 中心 / 右下角等九宫格），两种拖动都支持拟人化
  - **目标选「图片」时**：在限制区域内搜索目标图，点击命中项，或只把光标移过去不点击（两者共用同一套图片设置）。目标图支持截图 / 本地导入 / 剪贴板粘贴（截图自动把限制区域设为截图位置）；限制区域可在屏幕上**拖动·缩放**调整并预览，调乱了可**一键还原到截图时的区域**；相似度 50–100 可调；命中多个时可指定点击**第几个**（从上到下、从左到右）
  - 每类动作的**执行次数 + 间隔**放在各自基础设置里（点击次数 / 滚动次数 / 按键次数 / 输入次数 / 拖动次数）——它只是把动作**本体**多做几遍，运行条件只判一次、监听只走一遍
  - 另有**重复**设置（在「运行条件」卡片下方；移动与拖动除外）：可选**固定次数**或**直到条件满足**。每一趟都重新判定运行条件、重新触发监听、各记一条日志；运行结束后监听在全部趟数结束后触发一次，重复途中发生跳转即停止剩余重复
  - **直到条件满足**：至少执行一趟，趟末检查停止条件，满足即结束；支持最多趟数与最多时长，两项 0 均表示不限，先达到的上限生效。组合也支持此模式
  - **输入 → 键盘 → 文本**：一次输入整段文字（支持中文、换行）。本机模拟走逐字符注入（绕过键盘布局与输入法，中文直出）；CH9329 是真实 HID 键盘、物理上发不出汉字，改走剪贴板粘贴（自动备份并还原原剪贴板）。可勾**正则随机生成**——把内容当生成模式，每次执行随机产出（如 `[0-9a-z]{10}` → 10 位随机串），旁边有语法速查与预览
- **组合（Group）可嵌套**，支持批量多选合并、拖拽排序、序号显示、备注
- 单个动作可**禁用**（右键切换，运行时整步跳过，可撤销）
- **跳转**是独立动作：纯 goto，可设「最大重复次数」作防死循环上限
  - 目标按**别名**选择（像 goto 的标签）：给目标动作设一个别名，它就能被跳转；插入 / 删除 / 排序都与跳转无关。改别名时指向它的跳转自动跟随；旧存档（按身份 / 序号）运行时照常解析
- **监听动作**：可复制 / 粘贴（与动作列表共用剪贴板，组合除外）；在动作生命周期的 7 个节点追加动作——**运行条件判断前 / 判断成功后 / 判断失败后 / 运行前 / 运行成功后 / 运行失败后 / 运行结束后**。与普通动作同款配置（可含循环、条件、组合），可递归嵌套；条件类三个节点仅在该动作设了运行条件时触发

**运行条件**（满足才执行）
- 可添加**多条**条件，选择**全部满足（与）**、**任一满足（或）**或**自定义表达式**（如 `(@1 && @2) || !@3`，按序号引用条件）；每条可单独取反。停止条件复用同一套设置
- 时间段：在 / 不在某时段（可只设一侧作开放边界）
- **图片出现**：截图 / 本地导入 / 剪贴板粘贴取得模板，在限制区域内搜索——出现在区域内**任意位置**即算满足；相似度阈值可调。日志会打印实际匹配度，未匹配时也报出区域内最高相似度，便于判断是画面变了还是只差一点
- 方案与动作的条件判定通过时也会记录日志，显示实际观测结果；不满足、重复检查和搜索耗时同样可查
- **条件不满足时重复检查**：按设定间隔反复判定直到满足，等待期间可正常暂停 / 停止；不勾选则条件不满足即跳过该动作
  - 间隔填 **0** ＝ 判完立刻再判（不等待）；**最多次数**与**最多时长**同时生效、先到者结束，各填 0 即不限；间隔与时长都可选单位

**拟人化鼠标移动**（基于真人轨迹录制数据反推）
- 时长**次线性**于距离且带随机（10px≈440ms / 100px≈525ms / 1000px≈800ms，同距离每次不同）
- **前快后慢**速度剖面（峰值约在 1/4 处）、贝塞尔轻弧 + 相关抖动，同起终点每次轨迹都不同
- 大距离偶发过冲后回正；配套内置**鼠标轨迹录制器**用于采集真人数据调参
- **落点偏移**：移动 / 点击坐标 / 拖动可设一个像素半径，在目标点周围的圆内随机落点（与拟人化配套——轨迹拟人了、落点却分毫不差反而露馅）；0 = 精确命中，多次点击每次各自随机

**截图与取点**（配置图片条件 / 坐标时用）
- **截图**：冻屏后框选。鼠标移到某个窗口上会**自动框住它**，点一下即选中；拖拽则按自己框的来。选区支持八向手柄调整、整体拖动、方向键微调（Ctrl 调大小 / Shift 加速）
- 选好后有工具条：**矩形 / 椭圆 / 箭头 / 画笔 / 马赛克 / 文字** + 撤销（Ctrl+Z）+ 取消 / 完成；下面一行是**三档粗细 + 六种颜色**（选中某个标注时会同时应用到它）。马赛克是**涂抹式笔刷**（圆圈光标即笔刷大小），粗细即笔刷大小。标注不会画出选区之外；可再选中调整的是矩形 / 椭圆 / 箭头。⚠ 标注会画进目标图，导致与屏幕实际画面不一致而匹配不到——用作匹配模板时请勿标注
  - 画好的标注可以再调整，两段式：**点它的边框**即选中（边框加粗亮起）→ 选中后**内部拖动＝整体移动、边和角＝改大小**（箭头则是拖两端改指向），点图形以外的地方退出选中；方向键微调、Delete 删除、Ctrl+Z 回退。没选中时只有边框响应、有选中时不画新图形，所以「在已画的框里再画一个」和「拖走已有的框」永远不会搞混。马赛克是**实时预览**，拖拽时就能看到打码效果
- **编辑限制区域**：已有区域时直接把框画出来供拖动 / 缩放；**还没有区域时与截图一致**——悬停自动框住窗口、点一下即采用，或直接拖拽自己框。工具条有回退（Ctrl+Z）/ 取消 / 完成
- **坐标点选**：覆盖所有屏幕，任意屏直接点、自动识别落在哪块屏；方向键逐像素微调（Shift 加速），回车确认。显示器下拉仍保留，供手输百分比 / 预览锚定
- **图片匹配算法**：先在缩略图上粗筛、候选再回原图精验（整屏找一张横幅约 0.14 秒），精度与逐点全扫完全一致；相似度采用**模板结构加权**——文字 / 图标等有辨识度的像素权重高、平坦背景权重低。等权的"90% 像素一致"对白底小图标会让任何近色平坦区都算命中（实测一屏 25+ 个假命中），加权后结构必须对上才算数

**运行控制**
- 暂停 / 继续 / 停止，全局热键 **F9 / F10 / F11**（仅方案执行期间注册，平时把按键还给系统）
- **失败自动暂停**：方案设置默认开启，动作失败且没有「运行失败后」监听时暂停，按 **F10** 继续；设了失败监听则交给监听处理
- 运行页：当前动作高亮并**自动滚动跟随**、实时日志、进度条、方案级与动作级循环计数
- 运行页 **Esc** 直接回方案页（运行继续在后台）
- **运行悬浮窗（HUD）**：置顶显示当前动作 / 进度 / 循环 / 热键，带暂停·停止按钮；可拖动、可调不透明度（悬停临时变清晰）。进度条为连续滑动推进
- **运行时最小化本体窗口**：独立开关（在悬浮窗设置下），与「最小化到托盘」是两回事——后者只管你手动点最小化时收去哪里
- 运行时窗口下沉 / 最小化、不抢焦点；可配「结束后回到前台」

**系统托盘**：图标常驻，双击显示主窗口，右键直接选方案运行 / 停止 / 退出；可「最小化到托盘」。

**定时启动**（方案列表工具栏，全局单一）：让一个方案到点自动运行——**每日定时**（时:分:秒 + 可选星期）或**指定时间**（年月日时分秒，跑一次）；精确到秒；到点撞上正在运行可选「忽略」或「停止当前改跑定时」。被定时的方案在列表里带时钟标记。

**图片搜索占用核数**（配置页）：搜索期间会把选中的核吃满，默认用满全部核心（最快）；与游戏同时跑觉得卡顿时可以留几个核给前台。选项按本机核数生成。实测 14 核机器上只给 7 核仅慢 9%。

**其它**：浅色 / 深色 / 跟随系统主题、单实例、按需管理员提权、自定义数据目录、所有窗口记住位置与大小、自动更新可开关。

## 执行计时与日志

等待与条件重试使用可暂停的有效执行时钟。重试间隔会被剩余时限截断；到达上限后不再开始下一次检查或下一趟动作。已经开始的单次输入、图像搜索仍在各自的取消点结束，因此时限不是强制中断任意系统调用的实时截止线。间隔为 0 仍表示立即重试，会消耗 CPU。

有限组合收完配置的循环和子动作后才处理跳转；无限本体循环或无限条件等待会给已生效跳转留出口。同一组合收尾中出现多个有效跳转时，最后一个目标生效，各跳转在触发时消耗自己的次数额度。嵌套循环的总执行次数按各层配置相乘。

运行状态与日志历史分别传递：进度、暂停、完成和动作高亮只保存最新快照；界面每 80ms 调度一次，先更新状态，再最多呈现 64 条日志（集合更新预算约 4ms，不包含随后 WPF 布局与系统调度）。日志列表最多 2000 行，两侧列表均启用虚拟化。

磁盘写入由独立线程完成，不经过界面。界面队列最多 512 条 / 512 Ki 字符，磁盘队列最多 8192 条 / 2 Mi 字符；单条正文最多 4096 字符。高速循环或慢磁盘超过消费能力时保留近期记录，并明确汇总省略数量与其中的错误数量。清屏不影响磁盘记录，写入失败会在界面提示。新日志按 `run-yyyyMMdd-NNN.log` 轮转，每文件最多 8 MiB、保留最近 16 个；旧版每日日志不参与自动清理。

正常关闭会异步停止动作并在约 1 秒总预算内收尾日志；强制退出或无法及时返回的设备/磁盘调用可能留下未写完的尾记录。日志不用于逐条无损审计。

## 构建

同步到 `corp-win` 统一从仓库根目录运行 `bash tools/sync_corpwin.sh`。脚本先本地检查，再同步，并排除本地会话资料。测试命令与交付步骤见 [RELEASE.md](RELEASE.md)。单测包括重复直到条件满足、失败暂停和条件表达式；Win32/串口、真实抓屏、UI 及更新安装仍需在 Windows 环境验证。

性能回归可在 `MacroPilot.Tests` 下运行 `dotnet test -c Release --filter "FullyQualifiedName~Performance|FullyQualifiedName~RunTelemetry" --logger "trx;LogFileName=performance.trx"`。测试记录后台按键标记之间的真实等待时间、复杂编排动作序列、跳转规模、慢消费者和受阻磁盘下的缓存及显示延迟；TRX 保存观测数值。持续压力测试默认 10 秒，设环境变量 `MACROPILOT_SOAK_SECONDS=60` 可延长至 60 秒。这些测量使用假输入后端，不代替 CH9329 和实际目标程序的长时间验收。

**本体**（输出到 `%USERPROFILE%\MacroPilot_review`，不动桌面）：
```bat
cd MacroPilot
build.bat        :: 自包含，零依赖
build.bat fd     :: 框架依赖，体积小，需 .NET 8 桌面运行时
```

**安装器**（需 Flutter SDK + VS C++ 生成工具 + 7-Zip；会先发布本体再打包成单文件 SFX）：
```bat
cd MacroPilotInstaller_Flutter_WPF
build.bat
```

## 发布流程

详见 **[RELEASE.md](RELEASE.md)**。六步，顺序不能变：

1. 本地改源码（在当前版本基础上递增，两处版本号同步，`changelog.json` 补本版条目）
2. 用 `tools/sync_corpwin.sh` 同步到 corp-win，**跑单元测试 + 编译构建** —— 任一失败就回第 1 步
3. 产物同步回本地，清理 corp-win 上的中间产物
4. 按文件选择提交，检查暂存 diff、按实际协作者署名，再 push 到 GitHub
5. 维护两个源的发布文件（`version.json` + 本体包 + 安装器，三个都要传）
6. 走公网读两个源的 `version.json` 核对版本号（不下载文件）

> 核心原则：**测试与构建都过了才提交、才发布**。版本号取自程序集 `<Version>`，更新器只比较 `Major.Minor.Build` 且**严格大于**才算新版（不会降级）。
